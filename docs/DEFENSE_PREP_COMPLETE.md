## How to Use These Materials

### For Presentation Creation (Days 1–7 equivalent)

1. **Create slides from outline:**
   - Open `DEFENSE_PRESENTATION_OUTLINE.md`
   - Copy content into PowerPoint or Marp
   - Add diagrams from `docs/MERMAID_DIAGRAMS.md`
   - Style with your university's branding

2. **Prepare speaker notes:**
   - Use talking points from outline and Q&A document
   - Practice with timer
   - Record yourself to check pacing

3. **Create backup slides:**
   - Slides 17–20 in outline are ready to present
   - Include as hidden slides in PowerPoint (right-click → hide slide)
   - Practice navigating to them if Q&A goes deep

### For Demo Preparation (Days 3–4 equivalent)

1. **Set up demo environment:**
   - Follow "Pre-Demo Setup" in `DEFENSE_DEMO_RUNBOOK.md`
   - Test all systems (Docker, backend, UI, REST API)
   - Have Docker logs visible during demo

2. **Practice demo script:**
   - Walk through 8 steps verbally
   - Time each step
   - Identify slowest steps, prepare fallbacks
   - Have video backup ready

3. **Prepare test data:**
   - Sample email JSON provided in runbook
   - Real IMAP credentials (if available)
   - Alternative: Use HTTP POST endpoint to simulate email

### For Testing & Validation (Days 8–9 equivalent)

1. **Run testing checklist:**
   - Follow phases 1–7 in `WEEK2_TESTING_CHECKLIST.md`
   - Check off each item as you complete
   - Document any issues found

2. **Create test report:**
   - Fill in provided template
   - Save as `DEFENSE_TEST_REPORT.md`
   - Sign-off on readiness

### For Rehearsal (Days 10–11 equivalent)

1. **Set up rehearsal environment:**
   - Docker Compose running
   - Presentation slides ready
   - Demo machine prepared
   - Optional: 1–2 audience members for feedback

2. **Run full rehearsal:**
   - Follow structure in `WEEK2_REHEARSAL_GUIDE.md`
   - Time each segment
   - Practice transitions
   - Record yourself (optional)

3. **Handle Q&A:**
   - Use talking points from `DEFENSE_QA_BACKUP_SLIDES.md`
   - Practice with provided questions
   - Build confidence

### For Final Preparation (Day 14 equivalent)

1. **Create backups:**
   - PowerPoint, PDF, images
   - Store on USB drive + cloud
   - Verify all files accessible

2. **Record demo video:**
   - Full 5–7 minute workflow
   - Clear audio narration
   - Have as fallback if live demo fails

3. **Print materials:**
   - Presentation slides (handouts, 6 per page)
   - Demo script (for you)
   - Contingency plan (for you)
   - Business card/contact slide

4. **Final checklist:**

## Notes for Success

1. **Preparation pays off.** You've got detailed scripts, talking points, and contingencies. Trust them.

2. **Practice the demo multiple times.** It should feel natural, not robotic. Narrate as you go.

3. **Know your backup slides.** You might need them for deep technical questions. Have them memorized.

4. **Manage demo timing.** If Ollama is slow, skip to video. Don't let one slow step derail the whole presentation.

5. **Stay calm if things go wrong.** You have contingencies. Execute them smoothly.

6. **Engage with audience.** Make eye contact, speak clearly, pause for effect. Confidence is contagious.

7. **End strong.** Thank them, provide contact info, invite follow-ups. Leave them wanting to connect.
