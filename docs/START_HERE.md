## 🎤 На защиту: 3 готовых фразы

### Фраза 1 (Архитектура - 2 минуты):
```
"Проект использует классическую Spring Boot архитектуру.
Четыре слоя: Controllers, Services, Repositories, Database.

Главный бизнес-процесс — AI-конвейер:
1. Извлечение номера контейнера (Qwen 2.5)
2. Поиск контейнера в БД
3. Генерация черновика ответа (Llama 3.1)

Письма приходят через IMAP IDLE, обрабатываются синхронно.
Все компоненты используют Spring/Hibernate из коробки."
```

### Фраза 2 (На вопрос о защите):
```
"Защита на трёх уровнях:
1. UNIQUE constraint на message_id (дедупликация в БД)
2. Проверка findByMessageId перед сохранением
3. @Version для оптимистической блокировки (race condition)

Если Ollama недоступен — используются fallback-и:
- Regex для извлечения номера
- Template письма вместо AI"
```

### Фраза 3 (На вопрос об использовании):
```
"Используем из коробки Spring:
- Spring Security для аутентификации
- Spring Data JPA для работы с БД
- Spring Integration для IMAP IDLE
- Micrometer для метрик
- Flyway для версионирования БД
- Lombok для генерации кода

Это production-ready решения, не экзотика."
```
