## Section 3: Demo Fallback Video Recording (1 hour)

### Pre-Record Full Demo Workflow

**Why:** If live demo fails (Ollama slow, network issues), show video instead.

**Setup:**

```bash
# Install screen recording tool (if not already installed)
# macOS: QuickTime (built-in)
# Windows: Xbox Game Bar (Win+G) or OBS
# Linux: OBS or SimpleScreenRecorder

# Restart Docker Compose fresh
docker compose down -v  # clean slate
docker compose up -d  # background
sleep 150  # wait for Ollama models to load
```

**Recording Steps:**

1. **Open screen recorder:**
   - Start recording
   - Minimize unnecessary windows
   - Open browser tabs (login, ticket list)

2. **Run complete demo (5–7 min):**
   - Login (30 sec)
   - Show ticket list (30 sec)
   - Send test email (1.5–2 min)
   - Show new ticket in list (30 sec)
   - Click detail page (1 min)
   - Show approval action (30 sec)

3. **Narrate as you go:**
   - "Now I'm sending a test email..."
   - "The AI is extracting the container number..."
   - "Here's the draft reply generated by Llama..."
   - "Operator clicks Approve, and the ticket is closed."

4. **Save recording:**
   - Export as MP4 (1080p, 30 fps)
   - Filename: `Smart-Freight-Inbox-Defense-Demo.mp4`
   - File size: ~100–200 MB

**Checkpoint:**

## Section 4: Contingency Runbook (30 min)

### Create Emergency Procedures Document

```bash
cat > ~/Desktop/DEFENSE_CONTINGENCY_PLAN.md <<'EOF'
# Smart Freight Inbox — Defense Contingency Plan

Created: 2026-04-26

## Scenario: Live Demo Fails

### If Ollama Is Slow (Latency >10 sec)

1. **Recognize:** AI processing is taking longer than expected
2. **Say to audience:** "Ollama models are loading. Let me show a recording of this running smoothly."
3. **Action:** Stop demo, click to backup video slide
4. **Play:** Full 5-min demo video
5. **Resume:** Continue with Challenges & Roadmap slides (Slides 13–15)

### If Docker Won't Start

1. **Recognize:** Containers fail to start or health check fails
2. **Say to audience:** "Let me show you a pre-recorded demo instead."
3. **Action:** Skip to backup video
4. **Resume:** Slides 13–15

### If Network Connectivity Lost

1. **Recognize:** Can't reach localhost:8080
2. **Say to audience:** "Looks like we hit a network hiccup. I have a backup video prepared for exactly this scenario."
3. **Action:** Play backup video from local file (not streaming)
4. **Resume:** Slides 13–15

### If Projector/Screen Sharing Fails

1. **Recognize:** Audience can't see screen
2. **Say to audience:** "Let me restart the screen share / switch to HDMI cable"
3. **Action:** Troubleshoot (2–3 min max)
4. **If still failing:** Display slides from PDF on phone, narrate demo instead

### If You Forget Your Lines

1. **Recognize:** You freeze or blank out mid-sentence
2. **Action:** Pause 2–3 seconds, take water sip
3. **Say:** "Let me rephrase that..."
4. **Action:** Start over, simpler wording
5. **Continue:** Don't dwell on mistake

### If Audience Asks Unexpected Q

1. **Recognize:** Question is outside your prepared Q&A
2. **Action:** Pause, think (2–3 sec is OK)
3. **Say:** "That's a good question. Here's my take..."
4. **If unsure:** "I don't have data on that, but my hypothesis is... Here's a deep-dive slide on a related topic."

## Section 6: Pre-Defense Machine Checklist (30 min)

### Final System Verification

**Run this checklist the morning of defense:**

```bash
#!/bin/bash
# Save as: ~/Desktop/defense-preflight.sh

echo "=== Smart Freight Inbox Defense Pre-Flight Check ==="

# 1. Code clean
echo "1. Git status..."
git -C /path/to/inbox status --short
if [ $? -eq 0 ]; then echo "   ✅ Git OK"; else echo "   ❌ Git FAIL"; fi

# 2. Disk space
echo "2. Disk space..."
DISK=$(df / | tail -1 | awk '{print $4}')
if [ $DISK -gt 20000000 ]; then echo "   ✅ Disk OK ($DISK KB)"; else echo "   ❌ Disk CRITICAL"; fi

# 3. Docker available
echo "3. Docker..."
docker --version
if [ $? -eq 0 ]; then echo "   ✅ Docker OK"; else echo "   ❌ Docker FAIL"; fi

# 4. Presentation file exists
echo "4. Presentation..."
if [ -f ~/Desktop/Smart-Freight-Inbox-Defense.pptx ]; then 
  echo "   ✅ Presentation file OK"; 
else 
  echo "   ❌ Presentation file MISSING"; 
fi

# 5. Backup video exists
echo "5. Backup video..."
if [ -f ~/Desktop/Smart-Freight-Inbox-Defense-Demo.mp4 ]; then 
  echo "   ✅ Backup video OK"; 
else 
  echo "   ⚠️  Backup video MISSING (optional)"; 
fi

# 6. USB drive mounted (if using)
echo "6. USB drive..."
if [ -d /media/usb-drive ]; then 
  echo "   ✅ USB mounted OK"; 
else 
  echo "   ⚠️  USB not mounted (optional)"; 
fi

echo ""
echo "=== Pre-Flight Check Complete ==="
```

**Run it:**

```bash
bash ~/Desktop/defense-preflight.sh
```

**Checkpoint:**
- [ ] All checks pass (✅)
- [ ] No critical ❌ marks
- [ ] Warnings noted but not blocking
