## 🔥 ТОП МОМЕНТЫ (на которые обратить внимание)

### 1. **Дедупликация** (UNIQUE constraint)
```java
// EmailTicket.java:18
@UniqueConstraint(columnNames = "message_id")
```
Два письма с одинаковым Message-ID не могут существовать одновременно.

### 2. **Оптимистическая блокировка** (Race condition protection)
```java
// EmailTicket.java:105
@Version
private Integer version;
```
Если два потока одновременно изменяют запись → exception + retry.

### 3. **Graceful Fallback** (Resilience)
```java
// AiExtractionService.java:102-105
catch (Exception e) {
    return fallbackRegexExtraction(emailBody);
}
```
Если Ollama timeout → regex fallback + продолжаем работу.

### 4. **Транзакции** (Правильная архитектура)
```java
// AdminController.java (БЕЗ @Transactional!)
public ResponseEntity<String> reprocessAll(...) {
    int reset = ticketProcessingService.prepareForRetry();  // Короткая TX
    ids.forEach(ticketProcessingService::process);  // Каждый = новая TX
}
```
Контроллер БЕЗ @Transactional → не держит соединение БД часами.

### 5. **Out-of-the-box компоненты Spring**
- Spring Security (authentication)
- Spring Data JPA (ORM)
- Spring Integration (IMAP IDLE)
- Micrometer (metrics)
- Flyway (DB migrations)
