# Smart Freight Inbox — V1 MVP

AI-powered logistics email processing system.
Incoming freight enquiry emails are automatically processed: container numbers are extracted via Qwen 2.5, looked up in the database, and a professional reply draft is generated by Llama 3.1.

---

## Quick Start (demo on a single machine)

### Prerequisites
- Docker Desktop running
- [Ollama](https://ollama.com) installed and running locally
- Java 17+, Maven 3.9+

### 1. Pull AI models (one-time)
```bash
ollama pull qwen2.5:7b
ollama pull llama3.1:8b
```

### 2. Start PostgreSQL via Docker Compose
```bash
docker compose up -d
```

### 3. Run the application
```bash
./mvnw spring-boot:run
```

Or in PowerShell:
```powershell
.\mvnw.cmd spring-boot:run
```

The app starts on **http://localhost:8080**

## Architecture (V1 — synchronous monolith)

```
IMAP Server
    │  IMAP IDLE (push)
    ▼
EmailIngestionService   ← deduplication by Message-ID
    │  synchronous call
    ▼
TicketProcessingService
    ├─ Step 1: AiExtractionService  → Qwen 2.5  (extract container number)
    ├─ Step 2: ContainerLookupService → PostgreSQL (look up container data)
    └─ Step 3: AiDraftingService    → Llama 3.1 (generate reply draft)
         │
         ▼
   EmailTicket saved as DRAFT_READY
         │
         ▼
  Thymeleaf UI  ←  Operator reviews draft and closes ticket
```

## REST API (for programmatic access)

### Login
```http
POST /api/auth/login
Content-Type: application/json

{ "email": "operator@smartfreight.com", "password": "demo123" }
```
Response: `{ "token": "eyJhbGci..." }`

Use the token as `Authorization: Bearer <token>` header for subsequent requests.
