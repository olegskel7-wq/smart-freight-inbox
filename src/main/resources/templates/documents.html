How documents reach the customer

When an enquiry is classified as a document request, the AI determines which document is wanted and looks it up here by the extracted shipment identifier. If a matching document is on file it is attached to the reply draft; otherwise the ticket is flagged for the operator, who can attach an available document from the ticket page before sending.
